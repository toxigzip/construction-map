# Интерактивная Карта Строительных Объектов (Construction Map)

Веб-приложение для визуализации строительных объектов на интерактивной карте. Позволяет управлять статусами объектов, анализировать зоны покрытия и импортировать данные из Excel.

![Map Screenshot](https://via.placeholder.com/800x400?text=Interactive+Map+Preview)

## Основные Возможности

*   **🗺 Интерактивная карта:**
    *   Отображение объектов маркерами.
    *   Цветовая индикация статуса: 🟢 Активные, 🟡 Планируемые.
    *   Кластеризация и удобная навигация.
    *   Прямая ссылка на Яндекс.Карты для каждого объекта.

*   **📊 Аналитика и Зоны:**
    *   Отображение радиусов покрытия (5, 10, 15, 20, 50, 100 км).
    *   **Умная визуализация:** Зоны неактивных объектов заштрихованы для показа пересечений.
    *   **Фокус:** При клике на объект его зоны выделяются сплошным цветом и выводятся на передний план.

*   **💾 Управление Данными (No-Code):**
    *   **Импорт Excel:** Добавление новых объектов простым перетаскиванием таблицы.
    *   **Автосохранение:** Данные сохраняются в `LocalStorage` браузера — не пропадают при обновлении страницы.
    *   **Экспорт:** Возможность скачать обновленный файл `data.js` для фиксации изменений в коде.

## Быстрый Старт

Приложение работает полностью на стороне клиента (в браузере). Установка сервера не требуется.

1.  **Скачайте проект:**
    ```bash
    git clone https://github.com/toxigzip/construction-map.git
    ```
2.  **Запустите:**
    *   Просто откройте файл `index.html` в вашем браузере (Chrome, Firefox, Edge).

## Руководство Пользователя

### 1. Работа с картой
*   Слева — карта, справа — список объектов и панель управления.
*   Используйте фильтр "Статус" вверху сайдбара, чтобы скрыть ненужные объекты.
*   Клик по объекту в списке автоматически переместит карту к нему.

### 2. Импорт из Excel
Для добавления объектов создайте файл Excel (`.xlsx`) со следующими колонками (названия на английском важны):

| Колонка | Описание | Пример |
| :--- | :--- | :--- |
| **Name** | Название объекта | ЖК "Северный" |
| **Lat** | Широта (координаты) | 55.7558 |
| **Lng** | Долгота (координаты) | 37.6173 |
| **Status** | Статус (`active` или `planned`) | active |
| **Address** | Адрес | ул. Ленина, 1 |
| **Manager** | ФИО менеджера | Иванов И.И. |
| **Phone** | Контактный телефон | +7 999 000-00-00 |
| **Budget** | Бюджет проекта | 100 млн руб. |
| **Progress** | Прогресс (%) | 45 |
| **Description** | Описание | Жилой комплекс комфорт-класса |

1.  Нажмите кнопку **"📂 Импорт Excel"** внизу боковой панели.
2.  Выберите файл. Объекты добавятся мгновенно.

### 3. Как сохранить данные навсегда?
Так как у приложения нет базы данных, оно хранит новые объекты в памяти вашего браузера (`LocalStorage`).
Чтобы передать обновленные данные коллеге или зафиксировать их в репозитории:

1.  Нажмите кнопку **"💾 Скачать Data.js"**.
2.  Полученный файл замените на файл `js/data.js` в папке проекта.
3.  Сделайте `git commit`, если используете контроль версий.

## Технический Стек

*   **HTML5 / CSS3** (Flexbox, Grid, CSS Variables)
*   **JavaScript** (ES6+)
*   **Leaflet.js** — картографический движок.
*   **SheetJS (xlsx)** — обработка Excel файлов в браузере.
*   **OpenStreetMap** — провайдер карт.
